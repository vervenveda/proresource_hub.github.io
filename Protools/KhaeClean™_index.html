KhaeClean Protected Preview Guide
Sovereign Safe mode blocks external network resources. Scripts are off by default. When scripts are enabled, code runs in a sandbox without same-origin access, popups, modal dialogs, downloads, or top-page navigation. Connected Preview can contact external domains referenced by the pasted code. KhaeClean lists the domains it can detect and asks for confirmation before running. Dynamically generated addresses may not be visible to the static scan. Unknown JavaScript can still create heavy CPU or memory use. Use Inspect Code first, keep scripts off for unfamiliar code, and use Reset Preview when a preview behaves unexpectedly.
