Save, Print, Import & Export

Constraint-Based Layout Generator

This is a transparent rule-based concept generator—not AI structural optimization. It creates equal planning zones from your dimensions and constraints, then places the result into the editable CAD canvas.

Studio Guide

Expandable workspace

Wide hides the inspector. Focus hides both side panels. ⛶ enters browser fullscreen. The right inspector can be resized on desktop.

Drawing

Choose a tool, click-drag, and release. Doors, windows, text, and symbols are click-to-place. Wheel zooms around the pointer.

Units

All geometry is stored internally in millimeters. Changing the unit selector changes display and input conversion without changing physical size.

Protection

Drafts autosave locally. Important destructive actions create recovery snapshots. Saved projects are mirrored between IndexedDB and a local fallback when space permits.

Backups

Use Save Local for IndexedDB storage, Save to Computer or Project JSON for a portable editable file, and export the complete project library regularly. Browser storage can still be cleared by the browser or device owner.

History and versions

Undo and Redo move through the current editing session. Explicit project saves also create named version records that can be restored or downloaded.

Shortcuts

Ctrl/⌘ S Save Local · Ctrl/⌘ Z Undo · Ctrl/⌘ Shift Z Redo · Ctrl/⌘ D Duplicate · Arrow keys Nudge · Shift F Focus · Esc cancel drawing or close a dialog.
