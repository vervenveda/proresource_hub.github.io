Using SixBit Bun™

  • Choose images or drag them into the dropzone.
  • Select a target format. “Preserve” keeps original bytes when no raster transformation is required.
  • Animated GIF preservation overrides resizing because browser canvas cannot retain animation.
  • SVG sanitation removes scripts, event handlers, external references, and embedded HTML.
  • Visual wrapping changes only the textarea display; copied and downloaded output stays exact.
  • BunLink creates a versioned JSON package with a checksum for later validation.
  • Download Manifest creates a metadata-only batch record suitable for KhaeZip archives.
