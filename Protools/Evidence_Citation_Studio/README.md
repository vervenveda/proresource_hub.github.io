Research principle

The application does not automatically decide whether a claim is true.

It preserves:

The claim

The source

The evidence relationship

The researcher’s reasoning

Conflicting evidence

Limitations and missing context

The current assessment

Source files

When a local file is selected, the studio records:

Filename

File size

Media type

SHA-256 hash

The file itself is not embedded or uploaded.

Citation notice

Generated citations are drafting aids. Unusual source types, institutional authors, laws, court opinions, archival records, datasets, audiovisual materials, translated works, and incomplete publication histories may require manual review against the current official style guide.

Privacy and storage
