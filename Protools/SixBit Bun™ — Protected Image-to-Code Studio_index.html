Using SixBit Bun™

  • Choose images or drag them into the dropzone.
  • Select a target format. “Preserve” keeps original bytes when no raster transformation is required.
  • Animated GIFs are preserved only when the output format is “Preserve”; selecting PNG, JPEG, or WebP intentionally flattens the first frame.
  • Protected SVG conversion removes scripts, embedded HTML, external references, CSS imports, external CSS URLs, and nested SVG data payloads.
  • Visual wrapping changes only the textarea display; copied and downloaded output stays exact.
  • BunLink creates a portable, self-contained JSON image package with SHA-256 integrity information. Base64 packaging may be larger than the original binary.
  • The hashed manifest and KhaeZip-ready ZIP include conversion settings, checksums, code files, converted images, BunLinks, and package metadata.
