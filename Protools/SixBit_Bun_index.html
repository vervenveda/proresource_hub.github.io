Coordinated tools

SixBit Bun prepares. KhaeZip protects.

SixBit_Bun_index.html is the gateway. SixBit_Bun_Studio_index.html is the complete image and code workspace. Its KhaeZip-ready package is a normal ZIP so it remains widely readable; KhaeZip v5 can then encrypt, verify, split, join, or preserve that package without changing the source images.
