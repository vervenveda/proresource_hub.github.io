# ProReSources Category Landing Pages

This package adds human-facing category landing pages without reorganizing the existing `Protools/` directory or replacing the public registry/master directory.

## Included

- Updated root `index.html`
- `categories/research/index.html`
- `categories/writing/index.html`
- `categories/design/index.html`
- `categories/media/index.html`
- `categories/productivity/index.html`
- `categories/code/index.html`
- `categories/files/index.html`
- `categories/network/index.html`
- `categories/assets/index.html`
- `categories/systems/index.html`

Each category page includes:
- Verve N Veda-style 333 ticker
- ProReSources header
- category dropdown
- hamburger category drawer
- return to All ProReSources
- category-specific tool cards
- navigation to every other category page

The underlying ProTools paths are not moved.

`Systems & Simulation` includes prepared non-linking cards for Empire Systems Lab™ and Khaemenes Field Lab™ until their final repository routes are registered.
