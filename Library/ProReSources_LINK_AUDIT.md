Connected Repository Destinations

The page contains 23 network cards. Twenty-two point to public GitHub Pages or repository destinations currently visible under the vervenveda account. Sanctuary is presented as a planned construction site until its repository is available.

Deployment Note

The landing page expects index.html at the repository root and the applications inside a sibling Protools/ directory. GitHub Pages paths are case-sensitive. Preserve spaces, trademark symbols, capitalization, apostrophes, and the exact filenames listed above.

The 333 Network card expects this entry file:

Protools/333_network/333_Network_index.html

If the 333 folder uses index.html instead, change the file value for the network-333 registry entry to:

333_network/index.html
